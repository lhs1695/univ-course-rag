# 检索失败分类（阶段 4–5 用）

日期：2026-09-01  
栈与阶段以当前合同 [`plan-6.md`](plan-6.md) 为准；历史阶段见 [`plan.md`](plan.md)、[`plan-2.md`](plan-2.md)、[`plan-3.md`](plan-3.md)、[`plan-4.md`](plan-4.md) 与 [`plan-5.md`](plan-5.md)。决策见 [`decisions/`](decisions/README.md)。本文只保留失败分类，不再维护技术栈表。

效果差时先归类再改层。禁止直接换更大生成模型或加 Agent 跳数。

| 失败类 | 信号 | 先动哪 | 先不动哪 |
| --- | --- | --- | --- |
| 库里没有 | 未上传 / 解析失败 / 切分丢掉 / **图里的字没抽到**（第一期无视觉） | 解析、切分、补传文本型资料 | 提示词、换 LLM |
| 检索没拿到 | 切片在库里，top-k 没有它 | embedding、chunk 大小、关键词、过滤是否过严 | 生成温度 |
| 拿到了没用上 | 切片在 prompt 里，仍胡编或没引用 | 提示、引用校验、k 是否太大 | 再加大 k 到整课 |
| 生成/产品问题 | 检索对，语气或权限不对 | 角色提示、鉴权 | 向量库品牌 |
