## 1. 分析目标（课程级，非个体画像）

| ID | 目标 | 可采取的教师行动（示例） | 明确不做 |
| --- | --- | --- | --- |
| G1 | 看见课内高频疑问与重复问法 | 补充讲义、课堂澄清、把代表问句加入回归题集 | 不推断「谁没学会」 |
| G2 | 区分依据不足 vs 系统失败 vs 正常复习重复 | 修资料/检索/引用；修服务稳定性；或标记暂不处理 | 不把失败当知识盲区 |
| G3 | 形成可修正的主题/意图/知识点候选 | 确认、拆分、改标签、记录原因 | 不自动发布为教学结论 |
| G4 | 行动后可回归 | 对代表问句重跑对照 | 无成绩数据时不做掌握度/挂科预测 |

## 2. 问句结果分类（与日志字段对齐）

代码枚举 `app.models.query_log.QueryOutcome`：

| 结果类 | 字段值 | 计入「知识缺口」？ | 说明 |
| --- | --- | --- | --- |
| 引用回答 | `cited_answer` | 否 | 已生成带引用回答（引用支持仍须人工/评测另判） |
| 依据不足 | `no_evidence` | **否（仅触发核查）** | 对应生成侧 `NO_EVIDENCE`；可能是资料缺口、检索过滤、问题表述等，**不得直接等同资料缺失** |
| 系统失败 | `failure` | **否** | 超时、5xx、依赖错误等；`error_code` 可辅助；**禁止计入知识缺口分子** |
| 未写入/未知 | `outcome is NULL` 等 | 否 | 统计时单独列「未分类」，不并入上述三类成功口径 |

`hit` 布尔字段不单独作为学情结论；学情描述层以 `outcome` 为主。

## 3. 描述层指标：分子 / 分母 / 排除

**默认统计范围：** 单一 `course_id` + 闭开时间窗 `[t0, t1)`（UI 须展示）。
**角色：** 默认只统计提问时 `member_role_at_ask` 为学生（或课程成员学生角色）；教师自测问句可另开开关，默认排除。
**去重「不同问句」：** 先 `strip` + 连续空白折叠 + 小写（中文无大小写则仅空白折叠）；完全相同字符串计 1 个 distinct；**语义近义不去重**（交给 PLAN-04 分组）。

| 指标 | 分子 | 分母 | 排除 | 可复算示例 |
| --- | --- | --- | --- | --- |
| 提问次数 | 窗内日志条数 | —（计数） | 非本课；可选排除教师自测 | 窗内 100 条 → 100 |
| 不同问句数 | 去重后 query 数 | — | 同上 | 100 条中 40 种文本 → 40 |
| 引用回答数 | `outcome=cited_answer` | 提问次数 | 失败/依据不足不计入分子 | 70/100 |
| 引用回答率 | 同上 | 提问次数 | 分母不含「未分类」时可脚注 | 70% |
| 依据不足数 | `outcome=no_evidence` | 提问次数 | **不**并入失败 | 20/100 |
| 依据不足率 | 同上 | 提问次数 | — | 20% |
| 系统失败数 | `outcome=failure` | 提问次数 | **不得**改名为盲区 | 5/100 |
| 系统失败率 | 同上 | 提问次数 | — | 5% |
| 未分类数 | outcome 空或其他 | 提问次数 | 须单独展示 | 5/100 |

**比例展示规则：** 每个比例旁显示 `n/N`；当 `N < 30`（课程窗内提问次数）时强制文案「样本有限，不做强结论」。

### 3.1 检索/回答评测指标（固定题集，与学情描述层分开）

沿用 [evaluation-results](evaluation-results.md) 分层，**禁止合成单一准确率**：

| 指标 | 分母约定 | 现行基线参照 |
| --- | --- | --- |
| 应答题事实要点通过率（端到端） | 全部应答题 | Dense 15/17；Hybrid 16/17（22 题开发者核验） |
| 已回答应答题事实要点 | 已回答的应答题 | 15/16；16/16 |
| 引用支持率 | 已回答应答题 | 16/16；16/16 |
| 严格预期页命中 | 已回答应答题 | 12/16；12/16 |
| 明显课外正确拒答 | 课外题 | 5/5；5/5 |

核验者分层：`developer` / `independent` / `end_user` 分列；互不替代。

## 4. 意图与知识点标签（候选 vs 确认）

### 4.1 意图类别（教师可改）

| 代码 | 含义 |
| --- | --- |
| `concept` | 概念解释 |
| `procedure` | 方法/步骤 |
| `example` | 例题/应用 |
| `compare` | 比较/总结 |
| `admin_oor` | 课程事务/超范围 |
| `other_uncertain` | 其他/不确定 |

规则或模型给出的意图均为 **candidate**；仅教师确认后为 **confirmed**。

### 4.2 知识点

- 来源：教师维护的课程章节/知识点轻量表；无大纲时标签为 `pending_taxonomy`。
- 禁止模型虚构整棵知识树作为权威体系。
- 状态：`candidate` → `confirmed` / `rejected` / `split` / `deferred`。

### 4.3 人工标注样本须覆盖的对照类型

1. 同一疑问不同改写
2. 同知识点不同意图
3. 语义相近但意图不同
4. 无法判断 / 应标不确定

### 4.4 可能原因标签（教师）

`coverage_gap` | `retrieval_citation` | `question_wording` | `normal_review` | `undecidable`

## 5. 语义分组质量指标与目标阈值

**正式跑分前**本阈值冻结为 `metrics-v1`：

| 指标 | 定义要点 | 目标阈值（结题争取） | 未达标时产品行为 |
| --- | --- | --- | --- |
| 成对精确率（同一疑问改写应同组） | 人工「应合并」对中被分到同组的比例 | ≥ 0.70（标注集 n≥30 对） | 保持候选+人工确认，不自动当结论 |
| 成对召回（不应漏合并） | 同上分母下的召回 | ≥ 0.60 | 同上 |
| 覆盖率 | 落入非单例组的问句占比 | 报告即可，不设硬门 | 单例必须可见 |
| 误合并/误拆分 | 案例清单 | 每轮至少各列 3 例（若发生） | 写入 PLAN-06 证据 |
| 教师修正率 | 修改或拒绝的候选 / 审过的候选 | 作工作流信号，**不**当算法质量唯一证据 | — |

若标注集达不到 n≥30 对：报告实际 n，阈值改为「流程可用 + 案例审查」，**不得宣称达到 0.70/0.60**。

LLM 辅助簇摘要：仅在当次授权且成本可控时做对照；默认路径仍为 Embedding 分组（见 PLAN-04）。

## 6. 隐私、留存与外部发送

| 项 | 规则 |
| --- | --- |
| 教师默认视图 | 不展示学生姓名、个人排名、个体问句轨迹 |
| 底层关联 | `query_logs.user_id` 存在 → **禁止**宣传「已完全匿名化」 |
| 用途 | 教学支持与资料改进；**禁止**用于评分、惩罚、排名、高风险决策 |
| 时间窗 | UI 必选；建议默认近 14 或 30 天（实现可选，须写进帮助文案） |
| 留存 | 提问日志随课程数据管理；结题交付说明须写清理/导出责任人；本卡不改库 |
| 外部 Embedding/LLM | 发送问句文本须**当次明确授权**；说明课程范围、用途、是否留存于供应商；本轮总预算约 ≤ 2 元人民币 |
| 导出 | 导出含原文问句时按课程权限；默认导出聚合统计 |

## 7. 样本与证据分层（禁止混用）

| 层级 | 含义 | 可支持的结论 |
| --- | --- | --- |
| Fake pytest | 无真实模型 | 接口/权限/状态机 |
| 合成/研究题集 | 明确标注非真实学生 | 功能流程 |
| 真实日志 | 课内真实提问 | 描述层学情线索 |
| 开发者核验 | 如现行 22 题 | 工程对照，非独立评测 |
| 独立核验 | 未参与开发者 | 质量主张的增强证据 |
| 用户试用 | PLAN-09 | 任务完成/失败点 |

**题集规模：** 60～80 道有标注题为**争取目标**；当前以实际题量报告（含 22 题基线）。扩充进度不阻塞 PLAN-02～05 功能卡，但阻塞「独立评测已完成」类宣告。

## 8. 复算示例（人工）

窗内 10 条：`cited_answer`×6，`no_evidence`×2，`failure`×1，NULL×1；其中 2 条 query 文本相同。

- 提问次数 = 10
- 不同问句数 = 9
- 引用回答率 = 6/10
- 依据不足率 = 2/10
- 系统失败率 = 1/10
- 未分类 = 1/10
- 知识缺口分子：**不得**用 2+1 或 3 宣称盲区人数
