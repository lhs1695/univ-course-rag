### 2.1 状态、并发与预算

- 合法主路径：`queued → running → succeeded|failed|cancelled|budget_exceeded`；另含 `cancel_requested`、崩溃 `interrupted`，后者仅显式 resume 回 `queued` 或失败。
- 同课同时仅允许 **1 个活跃调查**（queued/running/cancel_requested），新建冲突返回确定性错误。显式 retry = **同任务新 attempt**、递增 attempt；禁止后台静默重启终态任务。
- 合同初值：最多 **8 决策步骤 / 6 工具调用 / 8 模型调用（含至多 1 次 schema 格式纠正）**；累计执行 **120 秒**（跨 attempt，排队/人工等待不计）；最多 **12 引用**；摘要+结论合计 **≤6000 字符**。
- 下一调用前检查剩余额度；限额内合法发出的 `finish` 可成功。禁止静默整任务自动重试；同类可恢复工具错误最多重试 1 次并计累计预算；每次 provider/tool 调用必须有限超时。完成/取消/预算同时到达按 **取消 > 预算终止 > 成功完成**，无取消且 finish 已在限额内合法发出时允许 succeeded。

完整状态见 [任务合同 §3](teacher-agent-task-contract.md#3-任务状态合同)，计数/时间、超时、重试和竞争边界以 [§7](teacher-agent-task-contract.md#7-初始预算与可判定终止规则2026-10-26-用户确认) 为准；预算表仅维护在合同 §7，不在任务卡重复。

### 2.3 硬验收与 E5-A

- 真跑路径未 `confirm_external_processing`（及 M3 UI 确认）时，**创建前拒绝**，外部 LLM / Embedding / 语义分组调用计数必须各为 **0**；用外部路径 spies 验证，不能只凭 Fake 无网络推断。
- 报告重要结论能回溯 Document/页码；M3 Vite 必走：发起调查 → 报告 → 依据 → 点引用 → 原 PDF 页。来源删除/禁用/越权不展示内容。
- E5-A 固定 Fake/Replay 夹具：同课程/时间窗/样本快照，对照 A 统计列表、B 相似组（若可用）、C Agent 报告。开发者核验通过条件：预列必需事实均有授权来源；捏造引用=0；候选原因写成确定事实=0；`no_evidence` 不直接断言课件缺失；系统失败不归为教学问题；任务终态正确。
- 无真实教师参与不得宣称效率已验证；真实模型质量单列。详细夹具、空窗形态、分母与证据要求见 [任务合同 §9.1–9.2](teacher-agent-task-contract.md#91-api--ui-硬验收)。历史参考：`中期答辩材料/笔记/07-研究实验与评测方案.md`（冻结，非链接）。

## 3. 课程业务基础（PLAN-17，必做，与 Agent 并行盘点）

最小够用范围（结题冻结）：

| 能力 | 规格 |
| --- | --- |
| 学期 | 名称 + 起止；课程可挂一个学期 |
| 课内名单班 | 课内 `course_classes`（**课内名单班**，非教务行政自然班/教学班双轨）；学生经名单进班并成为 `course_members` |
| 名单 | CSV（学号/姓名/班级）；校验空行与重复；导入结果摘要 |
| 学院 | **演示级**最小实体：`colleges(code,name)`；用户与课程可选挂学院；管理员 CRUD；**不做**专业/年级树、按学院权限隔离、培养方案、真选课 |
| 个人主页 | **按角色**：学生＝姓名+学号+所属课内名单班；教师＝姓名+**工号**（**不展示班级**）；管理员＝姓名+角色（可有工号）；均可选显示学院；**不展示提问历史** |
| 资料协作 | 教师上传 → 管理员可见 → **启用检索**（两步）；删除/禁用沿用现有软禁用思路 |
| 资料夹 | 浅树≤2 层（根+可选一层子）；师生同树（学生只读）；整课检索（按夹限检索后置）；**交互演示级**：侧栏树/清晰导航、建改删顺手、支持换父级（仍受深度约束） |
| 权限默认 | 教师：本课上传与查看；管理员：启用检索、全站账号与学期/学院；名单导入：本课内教师或管理员皆可 |

先盘点现有表与权限矩阵，再写迁移；不另建平行 users/courses 体系。

2026-10-26 M4 / PLAN-17 最小实现口径：复用 `users.full_name/student_number`、`courses.semester_id` 与 `course_members.class_id`，新增 `semesters`、课内 `course_classes`；班级与成员通过复合外键绑定同一课程。管理员维护姓名/学号和学期，本课教师或管理员管理本课班级、导入名单。CSV 先匹配管理员维护的已有学生账号；缺账号、姓名不符、非学生、空行、重复学号及已有班级冲突均提供行号摘要，不自动开户或改全站身份。同文件重复学号全部拒绝，同班重复导入跳过，有效行同事务提交；数据库并发冲突整批回滚并返回 409。

新资料 ORM/数据库默认和上传入口均关闭检索；仅管理员可启用，本课教师可停用。学生仅可列出/打开已启用资料，教师可查看本课待启用资料，管理员无需加入课程即可查看和启用资料；此例外不扩展到问答、检索或 Agent 教师权限。资料 DELETE 改为关闭检索，保留原文、任务和 chunks，可由管理员重新启用。现存已启用资料不被迁移批量关闭。个人主页独立 `/auth/profile` 白名单按角色：学生含学号与课内名单班；教师含工号、不含班级；均可选学院名；无问答日志。班级语义统一称**课内名单班**（表仍为 `course_classes`）。迁移 `0015` 仅隔离验证，完整命令与未验收项见 [PLAN-17](tasks/PLAN-17-course-business-foundation.md)。

2026-10-27 业务优化增量（用户授权全上）：① 主页按角色 + users.employee_number 工号；② 最小学院实体（非权限边界）；③ 资料夹交互重做含换父级。任务卡：T-profile-role-fields / T-college-minimal / T-folders-ux-redesign。实现走 Codex；迁移号自 0017 起。
