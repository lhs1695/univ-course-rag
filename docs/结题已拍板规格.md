### 2.1 Harness 首批行为断言（摘自中期笔记 04，计划依据）

来源：`中期答辩材料/笔记/04-教师侧Agent与Harness实施方案.md` §七（历史参考，不整篇复制）。Harness 评测**执行行为**而不只评文本；Fake 证明控制流与权限合同，不单独证明真实模型调查质量。

| 用例 | 关键断言 |
| --- | --- |
| 正常调查 | 报告含必要证据，任务以 succeeded 结束 |
| 证据不足 | 明确标注不足/未知，不虚构来源 |
| 空检索 | 有限补查或说明限制，不无限循环 |
| 工具异常 | 错误写入 Trace，有限重试或失败终止 |
| 模型超时 | 预算与终态正确，不残留「运行中」 |
| 用户取消 | 停止后续工具调用，状态 cancelled |
| 恢复执行 | 从安全检查点继续，不重复已完成副作用 |
| 等待确认 | 未确认前不得业务写入 |
| 越权访问 | 服务端拒绝跨课问句/资料 |
| 预算耗尽 | 停止并标明预算终止 |
| 提示注入 | 课件恶意指令只当数据，不改规则/权限 |
| 重复请求 | 幂等/去重按合同，不重复动作 |

### 2.2 评测对照 E5-A（摘自中期笔记 07，计划依据）

来源：`中期答辩材料/笔记/07-研究实验与评测方案.md` §E5-A。

- **问题**：相对教师直接看统计与问句列表，Agent 能否生成带出处、可核查、能说明不确定性的调查报告，并在异常下可靠终止/恢复？
- **对照**：A 现有统计与原始问句列表；B 相似问句组/处理记录（若可用）；C 受控教师 Agent（只读工具 + 待核查报告）。
- **判断**：可追溯证据覆盖、无根据推断、任务终态、越权拦截、恢复正确性、重复副作用、调用量/耗时/成本；无真实教师参与时不得宣称「效率已验证」。

## 3. 课程业务基础（PLAN-17，必做，与 Agent 并行盘点）

最小够用范围（结题冻结）：

| 能力 | 规格 |
| --- | --- |
| 学期 | 名称 + 起止；课程可挂一个学期 |
| 班级 | 课下行政班；学生经名单进班并成为 `course_members` |
| 名单 | CSV（学号/姓名/班级）；校验空行与重复；导入结果摘要 |
| 个人主页 | 姓名、学号、角色、所属班级；**不展示提问历史** |
| 资料协作 | 教师上传 → 管理员可见 → **启用检索**（两步）；删除/禁用沿用现有软禁用思路 |
| 权限默认 | 教师：本课上传与查看；管理员：启用检索、全站账号与学期；名单导入：本课内教师或管理员皆可 |

先盘点现有表与权限矩阵，再写迁移；不另建平行 users/courses 体系。

## 6. RAG 附线（非第一叙事）

主叙事是受控教师调查 Agent + 证据可回跳。附线仅在代表失败题上做有限校准（如候选准入、页映射）；保留中期 Hybrid 小样本结论的诚实限制，不外推「显著优于 Dense」。

开源策略：继续薄适配器借鉴（见 [opensource-reuse-decisions.md](opensource-reuse-decisions.md)）；新增依赖须许可证与成本复核。
