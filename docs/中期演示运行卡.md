## 目标与时间

- 汇报：约 6–8 分钟；产品实走：约 3–5 分钟。
- 只证明本机四课文本型问答原型、引用跳转、失败状态与已验收的权限边界。
- 不宣称人工事实正确率、通用多模态理解、生产部署或非开发者独立试用。

## 演示前检查

1. 启动本机 PostgreSQL；目标库必须是 `univ_course_rag_cn_v2`，migration `0011`，规模 **4 门课 / 27 份 PDF / 2,501 chunks**。课程名：线性代数、概率论与统计学、人力资源管理、教育学原理。
2. 确认环境（`.env.example` 默认已是 cn_v2；本机 `.env` 应指向同一库）：
   - `DATABASE_URL` / `POSTGRES_DB` → `univ_course_rag_cn_v2`。
   - `UPLOAD_DIR` → `corpus/local/cn-replace-2026-10-18/rechunk/uploads_v2`（约 57MB / 27 PDF）。
   - 演示建议：`QUERY_EXPANSION_BACKEND=llm`，`RERANKER_BACKEND=disabled`，`RETRIEVAL_STRATEGY=dense`。
   - **不要**把本机 `.env` 密钥提交进 Git。
3. 从仓库根启动后端：

   ```powershell
   backend/.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
   ```

4. 在 `frontend` 目录运行 `npm run dev`，浏览器访问 `http://127.0.0.1:5173`；登录必须走 Vite，不直连 `:8000`。
5. 检查 `/health`、`/ready`；`/runtime` 应报告 database=available、reranking.backend=disabled。`configured` 只代表本地配置状态，不代表模型供应商连通。
6. 确认 `student` 已加入四门演示课。正式演示只用 `univ_course_rag_cn_v2`；本场不重新入库、不临场换模型、不启用 rerank。

**任一步失败就停。** 不在答辩现场排查密钥、重建数据库或临时重跑全量评测；改用 [`中期答辩材料/彩排截图/`](../中期答辩材料/彩排截图/) 备用图并说明实际边界。

## 建议演示顺序

| 顺序 | 操作 | 预期 / 讲解重点 |
| --- | --- | --- |
| 1. 学生正常问答 | 登录 `student` → 我的课程 → **线性代数** → 提问 LA-01 | 有回答与引用卡片；点引用打开原 PDF 对应页（URL 含 `#page=`）。讲清楚引用用于回到原文核对，不等于主张已被证明。 |
| 2. 依据不足 | 仍在线性代数课，提问 LA-R | 问句见下；预期 `NO_EVIDENCE` / 依据不足；不能编造 SQL 或数据库步骤。 |
| 3. 教师一眼 | 登录 `teacher` → 线性代数 → **课程资料** 与 **问答反馈** | 资料列表可见入库状态；反馈页可见计数/趋势。不强调「抽取文本较少」类文案（已去掉）。 |
| 4. Admin 系统状态 | 登录 `admin` → **系统状态** | 只展示三行状态表（数据库 / 向量模型 / 生成模型）与刷新；无总判断黄条。 |
| 5. 失败与重试（可选） | 优先展示既有截图；若现场时间充足再实走 | 已提交问句后制造后端中断，页面显示系统失败而非「依据不足」；「重试本次问题」必须发送原已提交问句。 |
| 6. 权限边界（PERM） | 访问未加入课程的问答页，或临时撤权后提问再恢复 | 预期无权限 / 403（前端：「没有此操作的权限…」）。撤权演示后**立刻恢复**成员关系。同名 PDF 不得跨课串读。 |

固定问句（取自 cn 题集已通过项）：

- **LA-01（有引用）**：`根据线性代数讲义，线性代数主要研究哪两类对象？`  
  预期：作答并引用 `01-linear-algebra-full.pdf` 附近页；答案弱校验常含「向量空间」「线性变换」（弱规则，非人工正确率）。
- **LA-R（拒答）**：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？`  
  预期：`NO_EVIDENCE` / 依据不足。
- **PERM（无权限）**：浏览器打开未加入课程的 `/courses/<courseId>`（实际 Ask 路由**没有** `/ask` 后缀），或临时从线性代数撤权 `student` 后再问 LA-01。预期无权限提示 / 403。演示后立即恢复成员关系。
- **可选宽泛题**：`如何解线性方程组`（同课）——演示查询扩展后仍应回到步骤/正文页；属已验收路径，有 LLM 波动时勿现场连试。

技术亮点口径（汇报用）：见 [中期答辩材料/答辩提纲.md](../中期答辩材料/答辩提纲.md)「技术亮点」四条；中期主演示 dense、rerank 关。指标全称对齐 [`中期报告-修订稿.md`](../中期答辩材料/中期报告-修订稿.md)。

## 汇报数字怎么说（cn_v2 / 新四课）

- 库规模：**4 / 27 / 2,501**（课 / PDF / chunks），migration `0011`。
- **旧弱规则摘要**：16 道（每课 3 答 + 1 拒答）预期文档/页命中 **12/12**、拒答 **4/4**、系统失败 **0**；答案侧是弱规则/AI 预标，**不是人工事实正确率**，原始逐题 JSON 不在可跟踪目录。
- **当前 22 题真实模型小样本对照**：Dense / Hybrid 全部应答题中的事实要点通过率（即端到端可答题成功率）**15/17 / 16/17**；已回答应答题中的事实要点通过率 **15/16 / 16/16**；已回答应答题中的引用支持通过率 **16/16 / 16/16**；严格预期页命中 **12/16 / 12/16**；明显课外问题正确拒答 **5/5 / 5/5**。verifier=developer，不是独立评测；指标不得合成单一准确率。详见 [结果报告](../中期答辩材料/研究证据/results/retrieval-compare-2026-10-20.md)。
- 余弦阈值 `0.45` 未校准；演示未启用 rerank；真实供应商人民币账单未核对。
- OCR、纯图片、可靠公式恢复与图表理解未覆盖。
- 当前口径仅为上表 **4 / 27 / 2,501**（中文四课）。

## 收尾与故障降级

1. 若做过成员撤权，立刻恢复 `student` 在四门演示课的成员关系并核对课程列表。
2. 不在现场清理数据或修改题集；结束后可停止本轮启动的前后端进程。
3. 真实模型返回异常时不循环重试、不切换供应商；保留失败状态，转用 [`中期答辩材料/彩排截图/`](../中期答辩材料/彩排截图/) 继续汇报。
