# 试用课与中期汇报走位

目标：用一门真实试用课，在本机完整展示“教师上传资料 → 学生依据课内资料提问 → 教师查看学情 → 删除依据后拒答”。这是校园大创阶段成果演示，不代表已完成校园网生产部署。

## 一次性准备

1. 按 [`midterm-notes.md`](midterm-notes.md) 启动数据库、后端和前端，只使用 Vite 输出的浏览器地址。
2. `python -m app` 只创建缺失的演示账号，不创建课程。若还没有试用课，先用 admin 在“课程”页创建一门课，并将 teacher 设为教师、student 设为学生；已有则不要重复创建。
3. 在 `corpus/local/` 准备 1–3 份可抽取文本的 PDF、PPTX、DOCX、Markdown 或纯文本。旧二进制 PPT/DOC 不支持。不要提交真课件；扫描件、纯截图页和图片里的字不在当前能力范围。
4. 指定其中一份为“待删除资料”，提前选一个只由该资料支持的验证问题。其他资料不得包含同一答案，否则删除一份后仍可能正常命中。
5. 真模型演示时，由维护者自行在本机 `.env` 设置硅基流动向量与 DeepSeek 生成配置并重启 uvicorn，确认切换完成后再上传课件。FakeEmbedder 与硅基流动不在同一向量空间；此前用 Fake 入库的资料必须从原文件重新入库，不能直接用于真向量问答。不得在聊天、截图、汇报材料或普通日志中展示 key。

若暂时没有云 key，可以用 Fake 模式检查页面连通性，但汇报时必须明确说明这不是一次真模型效果验证。

## 正式走位

### 1. 教师上传课件

1. 使用 teacher 登录，进入“我的课程”。
2. 在试用课一行点击“资料”，再点击“上传资料”，选择 `corpus/local/` 中的课件。
3. 等待状态从“等待中/处理中”变为“成功”。只有成功资料才进入后续提问。
4. 查看含文本单元数、抽取字符数和切片数。这些数字只说明文本是否被抽取并形成索引，不是答案质量评分；“抽取文本较少”也只是提示，不会自动删除资料。
5. 若显示“失败”，保留现场并按“库里没有”解释：先确认文件能打开、包含文本层且不是空文件；修正安全夹具后点击“重试”，等待同一资料重新入库成功，不把失败假装成已入库。

预期：资料表显示文件名和“成功”；教师可以看到“进入问答”“本课学生”“学情”和“删除”。

### 2. 学生提问并查看出处

1. 退出 teacher，使用 student 登录。
2. 在“我的课程”进入试用课“提问”。
3. 输入准备好的验证问题并提交。
4. 检查页面同时出现答案与“引用”表；引用应包含正确资料名、页码（格式可提供时）和摘录。点击一次“查看原资料”：PDF 尝试跳到引用页，PPTX/DOCX 只打开或下载原文件；未登录或非本课成员不能借链接绕过权限。
5. 再问一个课件明确没有覆盖的问题，用于学情页的“未命中/拒答”表。

预期：有依据的问题能回答并展示出处；无依据的问题显示“依据不足，课内资料未检索到相关内容”，不调用模型猜答案。

### 3. 教师查看学情

1. 退出 student，再用 teacher 登录。
2. 在试用课一行点击“学情”。
3. 页面会显示当前配置的提问留存天数。检查“高频问句”包含刚才命中的学生问题，“未命中 / 拒答”包含无依据问题；已到期但尚未物理清理的记录也不得进入聚合。

预期：两张表只汇总本课学生提问，显示问句、次数及必要时间，不展示学生身份。

### 4. 删除资料后复问

1. 教师返回试用课“资料”，对“待删除资料”点击“删除”。
2. 阅读确认框后确认删除；此操作会删除文件、入库任务和相关切片，不可恢复。
3. 退出 teacher，重新使用 student 进入同一课程，对完全相同的验证问题再次提问。

预期：在其他资料没有重复依据的前提下，同一问题变为“依据不足”。若仍能回答，先检查其他已上传资料是否含同一知识点，不要通过修改黄金题掩盖问题。

### 5. 管理员维护提问日志

1. 退出 teacher，使用 admin 登录，进入“日志维护”。
2. 点击“预览到期记录”，只查看当前留存天数、单批上限、本批数量和是否仍有下一批；界面不得展示提问原文或提问者。
3. 若安全夹具含到期日志，点击“删除本批”，阅读确认框后确认；若 `has_more` 为“是”，必须重新预览再删除下一批。普通教师和学生不能进入该页面或调用维护接口。
4. 若本次没有到期记录，保留 0 条结果即可，不为演示篡改真实提问时间。需要演示删除时，只使用专用临时数据库中的合成问题夹具。

预期：dry-run 不修改数据；显式删除只处理受限的一批，未到期日志保留。当前数据库删除不会立即从已有备份、快照或外部副本中抹除。

## 失败分类口播

“效果不好时先定位层次：资料没成功入库，是解析或切分问题；库里有切片但 top-k 没拿到，是检索问题；切片已经进入提示但答案没采用或没引用，是生成问题；检索正确但权限、文案或操作不对，才是产品层问题。”

不要看到失败就直接换更大模型、扩大上下文或接 OCR。当前没有 OCR/vision，图片中的文字抽不到属于已知边界。

## 现场检查清单

- [ ] 浏览器使用 Vite 地址，登录 Cookie 正常
- [ ] teacher 和 student 都属于同一试用课
- [ ] 课件来自 `corpus/local/` 且有可抽取文本
- [ ] 上传状态为“成功”后才提问
- [ ] 命中回答有正确资料名、页码/摘录
- [ ] 点击引用原资料一次，同课成员可访问且未绕过权限
- [ ] 无依据问题明确拒答
- [ ] 学情显示留存窗口，包含命中与未命中问句，不展示学生身份
- [ ] 删除目标资料后，同一验证问题转为拒答
- [ ] admin 先预览到期日志，再对安全夹具显式删除一批；页面不展示问题或身份
- [ ] 清楚说明数据库清理不等于外部备份即时抹除
- [ ] `.env`、key、真课件和上传数据均未进入 Git

浏览器实走完成后仍不能由维护者自行触发阶段 18 或 19：只有阶段 25 的非开发者真实反馈表明确出现相应问题时再判断。阶段 25 模板见 [`usability-test-template.md`](usability-test-template.md)。

## 非开发者试用要求

第四期阶段 25 使用 [`usability-test-template.md`](usability-test-template.md) 记录。试用者必须未参与本项目开发，并亲自完成上面的登录、上传、提问、引用、学情和删除流程；维护者可以说明任务目标，但不能代替点击。记录中只保留匿名角色、任务成败、卡点和原话摘要，不记录任何账号凭据或身份信息。
