# UI Trial Shared Brief（五版共用）

> **非中期答辩材料**：本 Brief 仅供 UI trial 五版试验；中期答辩口径以 `midterm-handoff/` 与 runbook 为准。

## 产品

- 产品名：**课程知识库**
- 定位：高校课程内、有依据、可核对的智能问答（中期演示：线性代数 / 概率论与统计学 / 人力资源管理 / 教育学原理；正式库 `univ_course_rag_cn_v2`）。
- 核心闭环（必须可演示）：**提问 → 得到回答与依据 → 点引用 → 回到该资料的指定 PDF 页**。打开方式自定（新标签 / 侧栏 / 轻量翻页等均可）。

## 本轮范围

- **只做全部学生端页面**（含共用登录页的学生体验重做）。
- **不要改**教师专属页（本课学生 Members、问答反馈 Insights）与管理员页。
- 学生可点到的页面（现状路由，可推翻信息架构，但能力不能丢）：
  1. `/login` — 登录
  2. `/courses` — 我的课程
  3. `/courses/:courseId` — 课程问答（Ask）
  4. `/courses/:courseId/documents` — 课程资料

## 自由度（强制）

- **不要复现或「改良」现有 UI。** 把仓库里的学生端界面当作遗留实现，允许彻底重新设计信息架构、导航、布局、视觉与交互。
- **不要**把现有截图、现有组件树、现有配色/顶栏/双栏当作设计参考或约束。
- 页面全部元素、设计、以及为演示服务的功能形态都交给你决定；演示过关即可。
- Element Plus：可主题化，也可局部自绘/少用默认观感。
- 文案中文；品牌名沿用「课程知识库」（可微调副标题，勿擅自换成无关品牌）。

## 硬约束（仅这些）

- 引用必须能回到资料的**指定页**（闭环保留）。
- 优先适配现有后端 API / Cookie session；非必要不改后端契约。
- 技术载体：Vue3 + Vite + Element Plus（frontend/）。
- 本 trial 分支本地可运行学生路径；不 merge main、不 push。
- 禁止读/输出 `.env`、API Key、密钥、原题答案；不要动未提交的 `新开题资料.md`。
- **禁止通读全部 docs**；只读本 Brief、本版 skill/DESIGN.md、以及你实现时必须打开的 `frontend/` 与少量 API 客户端文件。

## 交付

1. 学生端全部页面可点、演示账号能走完闭环。
2. 根目录或 `docs/` 下短文 **`DESIGN-NOTES.md`**：本版选择了什么气质/结构/交互、为什么（一屏以内）。
3. 不要为炫技引入第二套 RAG、大依赖或 Agent 基建。
