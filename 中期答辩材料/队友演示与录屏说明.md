## 1. 项目一句话

面向高校课程的知识库智能问答：学生在授权课内提问 → 检索课内资料 → 生成回答并给引用 → 点引用回原文页；教师管资料与问答反馈；管理员管课程、成员与启用检索。本机演示，不宣称正式上线。

技术栈口述即可：Vue 3 + FastAPI + PostgreSQL/pgvector；Embedding 用硅基流动 BGE-M3；生成用 DeepSeek。

## 3. 本机怎么开

1. Docker Desktop 开着，仓库根：`docker compose up -d postgres`
2. 后端：`backend` 下用 venv 起 uvicorn，监听 `http://127.0.0.1:8000`
3. 前端：`frontend` 下 `npm run dev` → **[http://127.0.0.1:5173](http://127.0.0.1:5173)**（用 Vite，不要直接用 :8000 登录页）
4. 本机 `.env` 需有 SiliconFlow（Embedding）与 DeepSeek（生成）Key；**不要把 Key 写进 PPT / 群 / 仓库**

负责人本机若已在跑，可直接用上述地址。换电脑需自备 Docker、库数据、Key 与 `UPLOAD_DIR` 路径一致。

## 5. 建议录屏 / 截图流程（约 5–8 分钟可讲完）

### 学生（主线）

1. 登录学生 → 课列表确认四门、前两门为机器学习 / 智能移动机器人  
2. 进一门课 → **资料**：点开 PDF / PPTX，确认**页内预览**（缩放、翻页）；下载按钮可顺带点一下说明「仍可下载」  
3. 进 **问答**：提一个课内问题 → 有回答 + 依据/引用 → **点引用**回到原文页（PDF 带页码）  
4. （可选）提一个明显课外问题 → 应出现「依据不足」，不编造  

### 教师

1. 登录教师 → 同一门课资料树 / 上传入口（演示「能管资料」即可）  
2. **问答反馈**：看汇总数字与高频问句表（不必讲复杂指标）  

### 管理员

1. 登录管理员 → 课程 / 成员 / 资料「启用检索」仍在（两步启用：入库成功后再启用）  
2. （可选）学院 / 学期等业务页扫一眼，证明三角色业务在  

导航里**不应再出现**「课程调查」类调查 Agent 入口（产品已撤；结题若做教师分析是另一条线）。

## 6. 推荐提问（按课）

问句尽量贴近课件标题/目录；太泛可能「依据不足」，属正常。

### 线性代数（经典演示）

- **有引用**：`根据线性代数讲义，线性代数主要研究哪两类对象？`  
- **拒答**：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？`  
  预期：依据不足，不编造 SQL。

### 机器学习

- `线性模型的基本形式是什么？`
- `贝叶斯决策的基本思想是什么？`
- `什么是过拟合？`
- `回归分析讲了什么？`  
避免只问一句「什么是监督学习」就当失败——资料里若表述分散，可能依据不足；换上列更贴课件的问法。

### 智能移动机器人

- `根据课程资料，简述智能移动机器人课程关注的主要内容。`
- 或围绕感知 / 定位 / 地图构建 / 路径规划 提问。

### 教育学原理

- 结合具体讲义/PDF 标题提问（打开资料页看文件名再拟问）。  
- 资料应能**页内打开**；若打不开先找负责人查路径，勿在录屏里长时间卡死。

## 7. PPT 叙事建议（与报告对齐）

1. **问题**：课内资料散、通用大模型缺来源 / 易超纲  
2. **做法**：课内知识库 + RAG + 引用回原文；三角色权限  
3. **中期成果数字**：用上面 **§2.A**（4/27/2501、22 题分层结果）  
4. **演示**：用 **§2.B** 当前四课录屏（机学、机人置前好看也好讲）  
5. **后续（结题）**：业务与页面打磨、资料解析与检索质量；教师侧「课问答分析 / 备课参考」为附线，**不要吹成已上线 Agent 平台**

困难点可一句话带过：部分扫描/纯图/公式页文字提取不完整，会影响个别问答依据（报告已改白话表述）。
