## 1. 项目简介（PPT 首页 / 背景页）

**问题**

- 高校课程资料散在讲义、课件、参考文档，学生找可靠依据成本高  
- 通用大模型容易缺来源，或回答偏离本课范围  
- 教师难以从日常提问里系统看到共性疑问与资料缺口  

**我们做什么**

建设面向高校课程的**知识库智能问答 + 教学反馈**系统，服务**学生 / 教师 / 管理员**三类角色。

- 管理员：课程组织、成员权限、资料管理与检索启用  
- 教师：建设课内知识库、看学生问答反馈  
- 学生：在授权课内提问，查看回答依据并回原文位置  

**技术栈（一页即可）**

Python / FastAPI · Vue 3 · PostgreSQL / pgvector · Embedding（硅基流动 BGE-M3）· 生成（DeepSeek）

**目标表述（与报告一致）**

业务流程完整、权限清晰、问答可靠、可本地运行和演示；在业务与 RAG 主线完善后，再建设轻量级教师侧问答分析助手（整理常见问题与备课参考），**不要吹成已上线通用 Agent 平台**。

## 2. 研究主要内容（PPT：研究内容，建议 1～2 页）

主线：**课程业务 + 三角色页面 + 课内知识库 + RAG 问答与引用**。  
优先：基础业务、权限、知识库质量、演示体验 → 再做教师侧轻量分析助手。

| 序号 | 研究内容（报告口径） | PPT 可写短句 |
| --- | --- | --- |
| 1 | 多格式资料治理与可追溯索引 | PDF/PPTX/DOCX/MD/文本 → 解析切分 → 来源可回跳；扫描/公式页再补 OCR |
| 2 | 课内混合检索与证据筛选 | Dense + 关键词；召回/融合/筛选；固定题集对照 |
| 3 | 证据约束生成与引用核验 | 有依据才答；依据不足可拒答；分层评事实/引用/页码/拒答/故障 |
| 4 | 教学业务、三角色与权限 | 学期/班级/名单/主页；资料两步启用；角色可见范围清晰 |
| 5 | 课程反馈与效果评测 | 教师端汇总与高频问；固定题集评测支撑改进 |
| 6 | 本地运行与交互可靠性 | 本机可跑；SSE 流式问答；启动/迁移/异常可复现 |
| 7 | 教师侧课问答分析 Agent（附线） | 自然语言汇总提问、关联课件、备课参考；**主线就绪后再做** |

**相对开题的调整（可放小字或单独半页）**

原计划 MySQL、Chroma/Milvus、LlamaIndex 等 → 现为 **PostgreSQL/pgvector + 模块化 RAG**，并接入大模型服务。结题仍优先业务、三角色与 RAG 质量，而非换栈重构。

## 4. 项目实施进展（PPT：已开展工作 + 困难，建议 2 页）

### 4.1 已开展的工作（报告六点 → 幻灯片条目）

1. **架构与基础业务**：FastAPI + Vue3 + pgvector 本机原型；用户/课程/成员/资料/入库任务/切片/问答日志等模型；重心是教学业务、三角色与 RAG。  
2. **资料处理与来源定位**：多格式上传解析切分索引；课内检索生成；引用摘录与原 PDF 页入口。中期基线：**四课 / 27 PDF / 2,501 切片**。  
3. **权限与异常区分**：课程成员权限；无权限路径可演示；**依据不足 ≠ 系统故障**；部分资料有「需核对」提示。  
4. **教师问答反馈**：资料/成员管理；反馈汇总与高频问句；为后续分析助手留接口基础。  
5. **真实模型对照与分层核验**：22 题 Dense / Hybrid；事实要点、引用支持、页命中、课外拒答分层记录（详见 §5）。  
6. **问答交互与流式返回**：等待态、依据不足/系统错误区分、失败可重试；支持 SSE 流式。

### 4.2 困难与对策（报告三点，PPT 各一行）

| 困难 | 怎么讲 | 对策（报告口径） |
| --- | --- | --- |
| 部分 PDF 页面文字提取不完整 | 扫描/纯图/公式页文本不全 → 个别问答缺依据或页不准 | 重点页 OCR + 人工核对；完善解析检查与补录 |
| 检索与引用定位仍有优化空间 | Dense 与 Hybrid 整体接近 | 融合筛选、引入重排、固定题集回归 |
| 教学业务与操作可靠性仍须完善 | 学期/班级/名单/主页等结题继续打磨 | 补业务关系与权限；资料生命周期与 SSE 异常回归 |

## 9. 建议录屏 / 截图流程（约 5–8 分钟）

### 学生（主线）

1. 登录 → 四门课、前二为机器学习 / 智能移动机器人  
2. **资料**：PDF/PPTX **页内预览**（缩放、翻页）；下载可点一下说明仍支持  
3. **问答**：课内问 → 回答 + 引用 → **点引用回原文页**  
4. （可选）明显课外问 → 「依据不足」  

### 教师

1. 资料树 / 上传入口  
2. **问答反馈**：汇总与高频问句  

### 管理员

1. 课程 / 成员 / 资料「启用检索」（入库后再启用）  
2. （可选）学院 / 学期业务页扫一眼  

导航**不应出现**「课程调查」调查 Agent（已撤）。

## 10. 推荐提问（按课）

### 线性代数

- 有引用：`根据线性代数讲义，线性代数主要研究哪两类对象？`  
- 拒答：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？`  

### 机器学习

- `线性模型的基本形式是什么？`  
- `贝叶斯决策的基本思想是什么？`  
- `什么是过拟合？`  
- `回归分析讲了什么？`  

### 智能移动机器人

- `根据课程资料，简述智能移动机器人课程关注的主要内容。`  
- 或围绕感知 / 定位 / 地图构建 / 路径规划  

### 教育学原理

- 对照资料页文件名拟问；应能页内打开。
