## 二、项目简介

本项目的发起基于教育数字化转型背景下，高校数字化教学资源利用率低、传统人工答疑响应滞后且低效的现实痛点。针对通用大模型在专业教学场景中存在的“知识幻觉、缺乏事实依据、无法权限隔离”以及“无法反哺教学”等问题，本项目设计并实现了一套基于大模型与RAG技术的高校课程知识库智能问答系统。

项目以 Python 为核心开发语言，采用 FastAPI 异步框架搭建后端，Vue3 与 Element Plus 构建前后端分离的现代化 B/S 架构。AI 核心层依托 LlamaIndex 框架，结合最新的 DeepSeek-V4 大语言模型，通过语义切分、混合检索与 Rerank 重排机制，实现精准、具备引用源可追溯的流式智能答疑。同时，系统利用大模型对学生提问日志进行深度语义聚类分析，通过 ECharts 渲染出直观的学情分析看板。

项目预期将打破课程资料的“数据烟囱”，为学生提供24小时在线的高可信AI助教，同时以量化学情反哺教师教学，为高校“AI+教育”的垂直应用落地提供典型示范。

## 三、立项依据

### （一）行业研究现状和发展动态

**研究现状与意义：**

当前，国内外关于“大模型+垂直领域”的研究正如火如荼。国外（如哈佛大学 CS50 团队）已开始尝试引入专有 AI 助教协助日常教学。国内各大高校也积极推进数字化校园建设。然而，现有系统多停留于简单的“知识检索”或“通用聊天”，缺乏针对高校专业理工科课程（公式多、逻辑强、图表多）的垂直优化。研究基于 RAG 的课程知识库，不仅能将教师从低效的重复答疑中解放出来，更能通过数据挖掘实现因材施教，对推动高等教育信息化向智能化迈进具有重要指导意义。

**项目已有基础与研究积累：**

项目团队成员均来自计算机及相关专业，具备扎实的 Python 编程功底，熟练掌握 FastAPI 异步 Web 开发、MySQL 数据库设计及 Vue3 前端工程化开发。团队前期已深入调研了 RAG 核心算法，并在本地成功跑通了开源的小规模文档问答原型，验证了技术路线的可行性。

### （二）主要研究内容

**基于高级 RAG 架构的高校复杂教学资料精准检索机制研究：**

研究如何针对理工科多格式课件进行语义切分，并优化混合检索与 Rerank 算法参数。

**多角色联动与全平面业务隔离的权限系统设计：**

设计符合高校教学行政逻辑的 RBAC 权限控制模型，重点攻坚向量元数据过滤技术。

**基于 LLM 语义聚类的学情分析算法与可视化系统开发：**

研究如何利用大模型对海量、口语化的学生提问文本进行去噪、聚类与核心盲区提炼，并设计面向教师的数字化教学看板。

**低延迟、高并发的异步流式对话全链路优化：**

研究 FastAPI 异步中间件与前端 EventSource 技术的配合，解决大模型生成式回答的端到端吞吐率优化问题。

### （三）创新点与项目特色

**技术创新：**

高可信的学术引用溯源机制。系统摒弃了传统大模型的“盲目生成”，大模型给出的每一个知识点均基于教师上传资料生成的知识库，从根本上遏制了 AI 幻觉，保证了教学系统的严谨性。

**功能创新：**

从“单向问答”到“学情反哺”的闭环设计。项目不再局限于工具属性，而是首创性地利用大模型作为“数据分析师”，对学生提问进行深度的语义聚类，直接为老师提供“知识盲区预警”，实现了以数据驱动教学复盘的闭环。

**应用特色：**

高度适配高校教学行政架构的垂直业务隔离。系统原生支持多课程独立运营，通过底层的向量过滤技术，确保各课程知识库既能独立服务，又能防范敏感教学资料跨课程越权访问。
