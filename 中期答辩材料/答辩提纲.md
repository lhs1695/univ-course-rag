# 中期答辩提纲（队友自做 PPT 用）

更新：2026-10-20（Asia/Shanghai）

> **用法**：可用本提纲**自行重做**答辩 PPT。仓内 `汇报PPT/中期汇报-v5.pptx` 与 `讲稿-v5.md` 仅为**参考稿**，终稿可由答辩同学改写。开题详文见仓库根 [`新开题资料.md`](../新开题资料.md)。

建议总时长 **6–8 分钟**；每页只讲有证据的事实。

---

## 1. 问题（开题「实际问题与研究意义」）

- 课程资料分散，自然语言问题难靠文件名定位
- 通用大模型回答流畅 ≠ 对应当前课程口径
- 需要：可回原文核对 + 依据不足提示 + 课程访问边界
- **一句话**：做有依据、可核对的高校课程问答，而不是通用聊天机器人

## 2. 业务闭环（开题「总体目标」）

按一条链讲清，不要堆功能列表：

**课程资料管理 → 授权检索 → 证据问答 → 来源核对 → 教学反馈**

| 环节 | 中期能演示什么 |
| --- | --- |
| 资料管理 | 上传/解析入库；页级质量门禁；PyMuPDF 文字路径 |
| 授权检索 | 课内成员边界；演示默认 **Dense** |
| 证据问答 | 有据回答 / 依据不足 / 系统失败分开 |
| 来源核对 | 引用摘录；打开原 PDF `#page=` |
| 教学反馈 | 高频问句、依据不足列表（线索，非成绩画像） |

三角色：管理员（账号/课程/授权）· 教师（资料状态 + 基础反馈）· 学生（提问 → 引用 → 回原页）

## 3. 三项特色（开题「项目特色」）

1. **可追溯的资料组织**：页码、质量记录、哈希/切分/索引版本可解释  
2. **课程内检索可对照**：演示默认 Dense；Hybrid / BM25 / rerank **已实现可开关，不作中期主结论**  
3. **可核对的证据回答**：只引实际上下文来源；合法引用 ≠ 事实主张被支持  

生成模型表述：**DeepSeek（`deepseek-flash`）**；Embedding：BGE-M3。不要写营销版号「V4 Flash」当现行名。

## 4. 中文四课证据

- 库：`univ_course_rag_cn_v2`  
- 规模：**4 门课 / 27 份 PDF / 2,501 chunks**  
- 课：线性代数、概率论与统计学、人力资源管理、教育学原理  
- 弱规则（非人工正确率）：可答题预期文档/页 **12/12**，拒答 **4/4**  
- 题集 AI 预标；阈值 0.45 **未校准**

## 5. 演示路径（固定问句）

线性代数课内：

1. **LA-01**：`根据线性代数讲义，线性代数主要研究哪两类对象？` → 有回答与引用，点开 `#page=`  
2. **LA-R**：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？` → 依据不足，不编造  

截图备用：`中期答辩材料/彩排截图/`；完整步骤：`docs/中期演示运行卡.md`

## 6. 诚实限制

- **事实正确 ≠ 引用支持**  
- 非 OCR / 公式 / 图表理解主线；非校园网生产部署  
- 供应商账单、人工事实复核、Demo Reset / 成本专项：**待验**  
- Hybrid/rerank 不作中期主效果结论
