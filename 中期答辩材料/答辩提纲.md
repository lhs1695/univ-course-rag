## 1. 问题（开题「实际问题与研究意义」）

- 课程资料分散，自然语言问题难靠文件名定位
- 通用大模型回答流畅 ≠ 对应当前课程口径
- 需要：可回原文核对 + 依据不足提示 + 课程访问边界
- **核心叙事一句**：如何让高校课程问答遵守课程边界、提供可核对依据，并在依据不足时正确停止？

## 2. 业务闭环（开题「总体目标」）

**课程资料管理 → 授权检索 → 证据问答 → 来源核对 → 教学反馈**

| 环节 | 中期能演示什么 |
| --- | --- |
| 资料管理 | 上传/解析入库；页级质量门禁；PyMuPDF 文字路径；`COVERAGE_INCOMPLETE`=部分页需核对（≠失败） |
| 授权检索 | 课内成员边界；演示默认 **Dense** |
| 证据问答 | 有据回答 / 依据不足 / 系统失败分开 |
| 来源核对 | 引用摘录；打开原 PDF `#page=` |
| 教学反馈 | 高频问句、依据不足列表（线索，非成绩画像） |

三角色：管理员（账号/课程/授权）· 教师（资料状态 + 基础反馈）· 学生（提问 → 引用 → 回原页）

## 3. 技术亮点（四条 · 中期主讲）

1. **课界权限贯穿**：检索/生成/打开原文件均需课内授权；未授权拒绝（截图 10 + 运行卡 PERM）。勿夸大未测范围。
2. **证据链到原文**：页级解析 → Dense（BGE-M3）→ deepseek-flash 受限生成与引用 → `#page=`（截图 03/04）。检索命中 ≠ 答案正确。
3. **失败语义对照**：有据 / 依据不足 / 系统故障 / 权限拒绝（截图 05/11/10）。无证据 ≠ 坏了 ≠ 答案正确。
4. **可审计评测与门禁**：4/27/2501；22 题 Dense/Hybrid 分层指标（见下）；PROB-F02 作真实限制；Keyword-only→最终 evidence=0。

**检索策略**：dense / hybrid / rerank **已实现可开关**——**主演示：dense，rerank 关闭**。不得宣称 Hybrid 显著更优。

**与开题「重点争取」对齐（诚实一句）**：混合检索对照已有小样本开发者核验结果，但仍非独立评测；同义问题组、成本专项等属后期；扫描/OCR/复杂公式与图表**未声称已完整实现**。
