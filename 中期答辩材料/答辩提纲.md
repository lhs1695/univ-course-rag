# 中期答辩提纲（队友自做 PPT 用）

更新：2026-10-20（Asia/Shanghai）

> **用法**：可用本提纲**自行重做**答辩 PPT。仓内 `汇报PPT/中期汇报-v5.pptx` 与 `讲稿-v5.md` 仅为**参考稿**，终稿可由答辩同学改写。开题详文见仓库根 [`新开题资料.md`](../新开题资料.md)。

建议总时长 **6–8 分钟**；每页只讲有证据的事实。

---

## 1. 问题（开题「实际问题与研究意义」）

- 课程资料分散，自然语言问题难靠文件名定位
- 通用大模型回答流畅 ≠ 对应当前课程口径
- 需要：可回原文核对 + 依据不足提示 + 课程访问边界
- **一句话**：做有依据、可核对的高校课程问答，而不是通用聊天机器人

## 2. 业务闭环（开题「总体目标」）

**课程资料管理 → 授权检索 → 证据问答 → 来源核对 → 教学反馈**

| 环节 | 中期能演示什么 |
| --- | --- |
| 资料管理 | 上传/解析入库；页级质量门禁；PyMuPDF 文字路径 |
| 授权检索 | 课内成员边界；演示默认 **Dense** |
| 证据问答 | 有据回答 / 依据不足 / 系统失败分开 |
| 来源核对 | 引用摘录；打开原 PDF `#page=` |
| 教学反馈 | 高频问句、依据不足列表（线索，非成绩画像） |

三角色：管理员（账号/课程/授权）· 教师（资料状态 + 基础反馈）· 学生（提问 → 引用 → 回原页）

## 3. 技术亮点（双叙事 · 中期主结论）

### A. 教学场景闭环

1. **课界权限贯穿全链路**：检索、生成、打开原文件都在授权课程内；未加入课程不可问答（403）。
2. **证据约束生成**：有依据才答；依据不足可拒，不编造课外步骤。
3. **引用可回原页**：回答附带来源摘录与页码，点开带 `#page=` 的原 PDF。
4. **三角色 + 教师反馈**：学生问、教师看资料与问答线索、管理员管人与课——不是单一聊天窗。

### B. 检索 / 生成技术

1. **页级解析 + 质量门禁**：PyMuPDF 提取文字层；空页/稀疏页可登记；哈希与切分版本可解释。
2. **向量检索 + 证据生成**：Embedding **BGE-M3**；生成 **DeepSeek（`deepseek-flash`）**；只引用实际送入上下文的来源。
3. **检索策略已实现可开关**：dense / hybrid（含 BM25）/ rerank 均可配置——**中期主演示：dense，rerank 关闭**；Hybrid/rerank 对照与调参放**后期**，不作中期主效果结论。

**勿宣称**：人工事实正确率、准确率百分比、已上线 Hybrid 主结论。

**与开题「重点争取」对齐（诚实一句）**：开题中的混合检索对照、同义问题组、成本专项等属**争取项**；中期已具备可开关能力与基础反馈，**尚未**完成对照实验与人工事实复核。

## 6. 现有不足（三条）

1. **评价未人工复核**：仅有弱规则命中与拒答；**事实正确 ≠ 引用支持**；无独立人工事实正确率。
2. **复杂资料未覆盖**：非 OCR / 扫描件 / 可靠公式与图表理解主线；纯图页覆盖不全。
3. **产品化待验**：检索阈值与同义分组未校准；供应商账单与成本专项待验；单机演示、非校园网并发部署。

## 7. 后期计划（四条）

1. **小样本人工复核**：抽检事实正确与引用支持是否一致。
2. **Hybrid / rerank 对照**：在固定题集上对比 dense 与可开关策略，有无收益都如实报告。
3. **教师同义问题组**：在确认费用与阈值后再开，服务备课线索而非成绩画像。
4. **结题试用 + 成本**：非开发者小范围试用与资源账单；**不承诺**公网生产部署。
