# 开题资料与中期报告差异记录

更新：2026 年 10 月 21 日

## 一、文档用途与对照范围

本文件用于说明《旧开题资料.md》与《中期报告-修订稿.md》之间的主要内容差异、调整原因及事实依据，便于中期材料核对，也可作为后续结题报告的追溯记录。正式中期报告以学校提供的《中期报告格式.md》为结构依据。

本次对照的开题基准是本包 [`旧开题资料.md`](旧开题资料.md)（已做格式修复，正文内容保留）；项目实际进展主要参考 [`中期报告-修订稿.md`](中期报告-修订稿.md)、[`docs/当前交接.md`](../docs/当前交接.md)、本包答辩提纲、演示验收摘要和 Dense/Hybrid 逐题对照报告。项目仓库现有说明指出，尚未找到可确认的原始获批开题文件；如学校要求逐字对应正式立项版本，提交前应再核对学校归档件。

本次调整的原则是：保留原项目题目和课程知识库问答的基本方向；依据当前代码、配置、测试和记录更新技术选型；清楚区分“计划实现”“已实现”和“已验证”三个状态，使报告内容与项目实际进展对应。原开题中“申请并获得 1 项软件著作权”的成果要求按项目负责人决定删除，不列入中期报告承诺。

## 三、关键实验结果及其解释边界

中期报告使用的是中文四课演示库 univ_course_rag_cn_v2，包含 4 门课程、27 份 PDF、2,501 个文本切片。22 题 Dense/Hybrid 结果来自真实模型运行，核验工作由项目开发者完成，属于开发者核验口径。

| 指标 | Dense | Hybrid | 解释边界 |
| --- | ---: | ---: | --- |
| 全部应答题中的事实要点通过率 | 15/17 | 16/17 | 分母包括未回答的应答题；PROB-F02 未回答计为失败 |
| 已回答应答题中的事实要点通过率 | 15/16 | 16/16 | 只统计实际给出答案的应答题 |
| 已回答应答题中的引用支持通过率 | 16/16 | 16/16 | 引用支持不等同于严格命中预期页码 |
| 严格预期页命中 | 12/16 | 12/16 | 反映严格来源定位情况，应结合引用支持指标共同解读 |
| 明显课外问题的正确拒答 | 5/5 | 5/5 | 当前题目覆盖明显课外问题，后续可扩展边界问题和困难拒答样本 |

Hybrid 共召回了关键词独有候选，但当前实现下没有 Keyword-only 候选进入最终 evidence；Dense 与 Hybrid 都在 PROB-F02 上返回依据不足。严格页码未命中还可能涉及合并切片页码和题集页序标注的口径差异。因此，中期报告将该实验定位为小样本对照与问题定位依据，并分别呈现检索表现、答案质量和来源定位结果。后续将通过门槛校准、页码映射复核和独立核验进一步完善评价证据。

此外，资料覆盖提示 20/27 表示 27 份演示 PDF 中有 20 份带资料级 COVERAGE_INCOMPLETE 警告，反映资料覆盖风险仍需复查；页级 empty/sparse/abnormal 明细正在作为页面级诊断能力的后续完善方向。教师页面的“部分页面需核对”是资料级提示，后续将结合页面级信息进一步定位解析与切分问题。该指标用于呈现资料质量检查情况，与问答准确率分开统计。

本轮 Hybrid runner 为诊断候选层额外执行了一次检索，因此本轮 latency_ms 与 embedding 调用量包含额外诊断开销。后续性能比较将使用统一 runner 和测量口径。Rerank 尚未启用，余弦门槛 0.45 将结合固定题集继续校准。

## 五、报告口径与证据记录规则

1. **实现状态**：结合当前代码和可运行功能路径记录已实现能力。
2. **验证状态**：附上对应测试、运行记录或截图/日志，并注明验证范围。
3. **评测来源**：清楚标注开发者核验、独立复核和用户试用等不同证据来源。
4. **后续工作**：使用“后续将完善”“拟开展评估”等措辞，区分当前进展与计划任务。
5. **引用与正确性**：分别报告事实要点、引用支持和严格页码命中。
6. **检索策略**：根据同一题集上的候选召回、最终证据、答案质量和运行代价评价 Dense、Hybrid 与 Rerank。
7. **复杂资料**：注明实际验证的资料类型和样本范围，并通过代表页面与问答任务持续评估解析质量。
8. **成本与经费**：分别记录 Token 用量、供应商账单、经费台账和票据，以可核对记录说明实际支出。
