1. 确认 `univ_course_rag_cn_v2`、前后端已起、`student` 加入四课。
2. 使用系统自带录屏或 OBS，浏览器只开演示页；勿打开 `.env`、DevTools Network Cookie、终端密钥。
3. 建议镜头（约 3–5 分钟）：
