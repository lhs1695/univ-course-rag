# 人工核验标注规则（v1）

更新：2026-10-20（Asia/Shanghai）  
适用范围：`02-人工核验题集-v1`；库 `univ_course_rag_cn_v2`；策略默认 Dense / rerank 关。

## 1. 角色与独立性

| 项 | 要求 |
| --- | --- |
| 理想 | 非本题作者的独立核验者 |
| 本轮若无独立人员 | 必须在结果表标注 **`verifier=developer`（开发者核验）**，答辩时不得说成第三方评测 |
| 盲测 | **先**写 `expected_*` 与 `must_include_points`，**再**看模型输出；禁止根据模型答案回改预期页来制造命中 |

## 2. 题目类型

| `category` | 含义 |
| --- | --- |
| `in_course_fact` | 课内事实：答案要点应能在指定资料页找到 |
| `term_paraphrase` | 术语/措辞差异：问法与课件用语不完全相同 |
| `cross_span` | 跨段或跨页：要点分布在多页或需串联 |
| `insufficient` | 依据不足：课内资料不应支持完整作答，预期拒答 |

## 3. 可答题判定（`should_refuse=false`）

分别打勾，**不得合并成一个「正确」分**：

1. **事实要点**：模型答案是否覆盖 `must_include_points`（允许同义表述；禁止课外发挥充当要点）。
2. **引用支持**：所给 citation 摘录/原文是否**真正支持**已答要点（有引用卡 ≠ 支持）。
3. **来源页**：citation 的文档名与页码是否落在 `expected_documents` + `expected_pages` 可接受范围内（允许 ±1 页若切分跨页，须在笔记说明）。
4. **未编造**：答案未引入资料未支持的步骤/数据/课外工具。

每题记录：`fact_ok` / `citation_supports` / `page_ok` / `no_hallucination` ∈ {pass, fail, unclear}。

## 4. 拒答题判定（`should_refuse=true`）

1. 系统应走 **依据不足 / `NO_EVIDENCE`**（或等价前端文案），**不得**给出可执行的课外步骤当「有据回答」。
2. **不得**把系统故障（上游 5xx、超时）记成「正确拒答」。
3. 若检索命中了字面相关但无关任务的片段却仍生成课外教程 → **fail**。

## 5. 禁止宣称

- 禁止把本集通过率写成「准确率 xx%」「显著优于…」除非有对照协议与完整分母。
- 禁止用 Fake pytest 或弱规则 12/12 替代本集结论。
- 禁止在未跑 Hybrid 时声称 Hybrid 更好。
