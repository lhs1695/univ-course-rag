## 1. 开场定位（约 40–50 秒）

各位老师好。我们做的是面向高校课程的**知识库智能问答与教学反馈**原型。

一句话：**学生在一门课里提问 → 系统只在该课授权资料里检索 → 生成带引用的回答 → 点引用回到原 PDF 页核对**；教师侧能看到问答统计与依据不足等线索，定位是教学反馈，**不是成绩画像**。

中期交付的核心，是这条**可信问答闭环**能在本机演示跑通，并且失败时说得清楚。我们不宣称已上生产，也不宣称通用 OCR、公式或图表理解已经完备。

## 2. 问题与边界（约 40 秒）

痛点三句就够：

1. 课程资料分散，自然语言问题难靠文件名定位；
2. 通用大模型流畅，不等于对应当前课程口径；
3. 多课并存时必须守课程访问边界。

核心叙事请记住这一句：

> **如何让高校课程问答遵守课程边界、提供可核对依据，并在依据不足时正确停止？**

---

## 3. 闭环怎么讲（约 60–70 秒 · 可配合实走）

业务链：**资料管理 → 授权检索 → 证据问答 → 来源核对 → 教学反馈**。

现场建议固定三步（线性代数课）：

1. **LA-01**：`根据线性代数讲义，线性代数主要研究哪两类对象？`  
   → 有回答、有引用；点开 PDF，URL 含 `#page=`。证明：课内可检索，证据链能回原文。
2. **LA-R**：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？`  
   → 依据不足 / `NO_EVIDENCE`，不编造 SQL。证明：该停的时候能停。
3. **PERM**（实走或截图 10）：未加入课程的问答页 → 无权限 / 403。证明：权限拒绝 ≠ 依据不足 ≠ 系统故障。

讲解时强调一句：**检索命中 ≠ 答案正确**；引用存在也不等于事实已被证明，只是供人核对。

三角色点到即可：管理员管账号课程授权；教师看资料状态与基础反馈；学生提问、看引用、回原页。教师反馈中期是**线索**，完整学情闭环在后期。

## 5. 指标怎么念（约 70–80 秒 · 防追问）

我们做了 **22 题真实模型** Dense / Hybrid 对照，并由**开发者**按规则核验——请说「开发者核验」，不要说成第三方独立评测。

**禁止**合成一个总准确率。请按修订稿全称念：

| 指标 | Dense | Hybrid |
| --- | --- | --- |
| **全部应答题中的事实要点通过率**（17 题为分母，未回答计失败） | **15/17** | **16/17** |
| 已回答应答题中的事实要点通过率 | **15/16** | **16/16** |
| 已回答应答题中的引用支持通过率 | **16/16** | **16/16** |
| 严格预期页命中 | **12/16** | **12/16** |
| 明显课外问题正确拒答 | **5/5** | **5/5** |

防追问三句：

- **页命中不叫引用错误率**；引用支持与严格页码是两件事。
- **5/5 只覆盖明显课外拒答**，不能说困难拒答已经验证完。
- 弱规则 12/12、4/4 只是辅助摘要，**不是**人工事实正确率。

详细分母与失败案例见 `研究证据/results/retrieval-compare-2026-10-20.md`。

Dense / Hybrid / rerank **已实现可开关**；主演示用 Dense，rerank 关闭。

本轮 Hybrid 在个别事实上略有差异，但 **Keyword-only 候选未进入最终 evidence**。口径必须是：

## 7. 失败四分 + 真实限制（约 40 秒）

四种状态分开讲：

| 状态 | 含义 |
| --- | --- |
| 有据回答 | 课内有证据，带引用作答 |
| 依据不足 | 正确停止，不编造 |
| 系统故障 | 服务异常，可重试（截图 11） |
| 权限拒绝 | 未授权（截图 10） |

口诀：**无证据 ≠ 坏了 ≠ 答案正确 ≠ 无权限**。

另外诚实报一条限制：**PROB-F02** 应答题在 Dense / Hybrid 下均返回依据不足，根因尚未定位——当作真实限制，不抹掉。

## 8. 学情未完成 + 后期三阶段（约 50–60 秒）

学情分析：**中期还没有做完**。现在有的是描述性统计与依据不足线索；完整闭环按报告设计为——

**问题分组候选 → 教师确认主题/知识点 → 记录处理动作 → 代表问题回归**（非成绩画像）。

后期按修订稿三阶段，顺序是「先可靠、再验证、后扩展」，**不承诺公网生产**：

1. **可靠性与证据质量**：资料生命周期、权限边界、引用页码与异常恢复；单题诊断 PROB-F02。
2. **学情分析 V1**：上面那条人机协同闭环；小规模任务试用找障碍。
3. **独立评价、流式/性能基线与结题收口**：未参与开发者核验代表题；先建当前请求—响应基线，再验流式、取消/超时与并发隔离；干净环境安装恢复与结题交付。
