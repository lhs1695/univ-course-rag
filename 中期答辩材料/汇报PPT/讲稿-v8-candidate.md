## 第 1 页 · 封面定位（约 35–45 秒）

**PPT 标题方向**：课程知识库 · 有据问答，通向教学反馈

各位老师好。我们做的是面向高校课程的**知识库智能问答与教学反馈**系统。

一句话产品主张：

> **有据可查的课内问答，并通向教师可核验的教学反馈——不是搜题机，也不是成绩画像。**

中期要证明的，不是「模型答得流畅」，而是这条路径能在本机跑通：

**学生在一门课里提问 → 只在该课授权资料里检索 → 生成带引用的回答 → 点引用回到原 PDF 页核对。**

教师侧目前能看到问答统计与依据不足等**线索**；完整的学情反馈闭环，按报告安排在后期。我们不宣称已上生产，也不宣称通用 OCR、公式或图表理解已经完备。

## 第 2 页 · 问题与边界（约 40–50 秒）

**PPT 标题方向**：课内问答不可信，因为难核对来源与权限

为什么要做这件事——三句边界就够：

1. **资料分散**：讲义、课件、参考文档散落各处，自然语言问题很难靠文件名找到可靠依据。
2. **流畅不等于对口**：通用大模型可能给出缺少来源、或偏离当前课程口径的回答。
3. **多课必须隔离**：学生只能访问已授权课程；跨课检索与打开原文都必须拦住。

请评委记住我们的核心问题：

> **如何让高校课程问答遵守课程边界、提供可核对依据，并在依据不足时正确停止？**

非目标也说清：**不是**全网搜题，**不是**用问答日志做个人成绩或教学质量评判。

## 第 3 页 · 钉回 PDF 的闭环（约 60–70 秒 · 可配合彩排图 / 实走）

**PPT 标题方向**：我们把答案钉回原 PDF 页

中期最想让人看见的能力，是一条可核对链路：

**问题 → 课程范围内的候选证据 → 带引用的回答 → 原 PDF 页。**

业务上对应：**资料管理 → 授权检索 → 证据问答 → 来源核对 →（后期）教学反馈**。

现场或彩排图建议固定讲「能钉回去」这件事——线性代数课、问句见文末附录 **LA-01**：有回答、有引用；点开后 URL 含 `#page=`。证明两件事：课内可检索，证据链能回原文。

讲解时加一句防误解：

> **检索命中 ≠ 答案正确；有引用 ≠ 事实已被证明——引用是给人核对的，不是自动免检章。**

三角色点到即可：管理员管账号与课程授权；教师看资料状态与基础反馈；学生提问、看引用、回原页。

## 第 5 页 · 分层验收（约 70–80 秒 · 防追问重点）

**PPT 标题方向**：验收看分层，不看「答得流畅」

我们在同一库上跑了 **22 题真实模型** Dense / Hybrid 对照，并由**项目开发者**按既定规则核验。请务必说「**开发者核验**」，不要说成第三方独立评测；后续计划邀请未参与开发的人员复核代表题。

**禁止**合成一个「总准确率」。主数字请按修订稿全称念——PPT 建议只放大这一行：

> **全部应答题中的事实要点通过率**（17 题为分母，未回答计失败）  
> Dense **15/17** · Hybrid **16/17**

其余分层用小字或口头补一句即可：

| 指标 | Dense | Hybrid |
| --- | --- | --- |
| 全部应答题中的事实要点通过率（17 题分母，未答计失败） | **15/17** | **16/17** |
| 已回答应答题中的事实要点通过率 | 15/16 | 16/16 |
| 已回答应答题中的引用支持通过率 | 16/16 | 16/16 |
| 严格预期页命中 | 12/16 | 12/16 |
| 明显课外问题正确拒答 | 5/5 | 5/5 |

防追问三句（建议背熟）：

1. **页命中不叫「引用错误率」**——引用支持与严格页码是两件事；本轮已回答题引用支持 16/16，严格页命中 12/16。
2. **5/5 只覆盖明显课外拒答**，不能说困难拒答已经验证完。
3. 弱规则自动摘要（如 12/12、4/4）**不是**人工事实正确率。

详细分母与失败案例见 `研究证据/results/retrieval-compare-2026-10-20.md`。

## 第 6 页 · Hybrid 不夸大（约 25–35 秒）

**PPT 标题方向**：检索有对照，但不宣称 Hybrid 更优

Dense / Hybrid / rerank **已实现可开关**；主演示用 Dense，rerank 关闭。

本轮 Hybrid 在事实要点上略有差异（16/17 vs 15/17），但修订稿写明：Keyword-only 候选本轮**未进入最终 evidence**，门槛与准入仍有校准空间；且本轮 Hybrid runner 含诊断重复检索，latency 不宜直接当最终性能结论。

口播必须落到这一句：

> **有对照，不宣称 Hybrid 显著更优。**

有无收益，用同一题集如实对照，不升格成架构胜利。

## 第 7 页 · 失败与权限（约 40–50 秒）

**PPT 标题方向**：失败与无权限也讲清楚

四种状态分开讲——口诀：**无证据 ≠ 坏了 ≠ 答案正确 ≠ 无权限**。

| 状态 | 含义 | 演示锚点 |
| --- | --- | --- |
| 有据回答 | 课内有证据，带引用作答 | LA-01 |
| 依据不足 | 正确停止，不编造 | LA-R |
| 系统故障 | 服务异常，可重试 | 彩排截图 11 |
| 权限拒绝 | 未授权课程，拒绝访问 | PERM / 截图 10 |

实走或截图讲 **PERM**：未加入该课的账号进问答页 → 无权限 / 403。证明权限拒绝与依据不足、系统故障是三条路。

再诚实报一条真实限制：**PROB-F02** 属于预期应回答的题，Dense 与 Hybrid 本轮均返回依据不足，根因仍在排查——当作已知限制，不抹掉。

## 第 8 页 · 学情 V1 与后期（约 50–60 秒）

**PPT 标题方向**：结题主线是学情反馈闭环

学情分析：**中期还没有做完。** 现在有的是描述性统计、依据不足列表与资料处理状态等线索；完整闭环按修订稿设计为——

> **问题分组候选 → 教师确认主题/知识点 → 记录处理动作 → 代表问题回归**  
> （人机协同；**不是**个人成绩画像）

后期按报告三阶段，顺序是「**先可靠、再验证、后扩展**」，**不承诺公网生产**：

1. **可靠性与证据质量**：资料生命周期、权限边界、引用页码与异常恢复；单题诊断 PROB-F02；覆盖警告与页级诊断推进。
2. **学情分析 V1**：上面那条确认—处理—回归闭环；小规模学生/教师任务试用，记录完成与失败点。
3. **独立评价、流式/性能基线与结题收口**：扩充题集并邀请未参与开发者核验；先测当前请求—响应基线，再验流式、取消/超时与并发隔离；干净环境安装恢复与结题交付。

收束一句：

> 中期结论——中文四课本机可演示；**课界 + 可核对依据 + 依据不足正确停止**有权限、证据链、失败四分法和分层评测支撑；数字有据、限制说清。感谢各位老师。
