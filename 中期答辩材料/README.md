# 中期答辩材料

给两位大创队友做**中期汇报答辩**用的材料包。本目录已纳入 Git，克隆本私人仓库即可拿到。

更新：2026-10-20（Asia/Shanghai）

## 项目一句话

面向高校课程 PDF 的**有依据、可核对**问答原型：学生提问 → 检索课内资料 → 生成回答并给出引用 → 点引用回到原 PDF 页。本机演示，不宣称生产部署或通用多模态。

## 演示与密钥（队友必读）

- **云 Key：队友自备**。Real 演示需要本机配置 SiliconFlow（Embedding）与 DeepSeek（生成）；Key 只写在本机 `.env`，**不要提交、不要贴进 PPT/聊天/公开群**。
- **Fake vs Real**：无 Key 时用 Fake 后端仍可看 UI 与三角色入口，但回答/检索不是真实语义效果。正式中期演示走 Real。
- **演示主机**：任意配好 Docker + `cn_v2` 数据 + `UPLOAD_DIR` + Key 的机器都可跑。负责人本机库内 PDF `storage_path` 可能是绝对路径；若点引用打不开，先核对 `UPLOAD_DIR` 是否指向 `corpus/local/cn-replace-2026-10-18/rechunk/uploads_v2`，仍不对则需路径校正或重入库（见根 README「常见坑」）。
- **仓库计划公开**：公开前务必确认未提交 `.env`、真实口令、Key、数据库 dump；演示账号若改过默认口令，以私聊为准且勿写进仓。
- **录屏**：建议队友自录 3–5 分钟无密码、无 Key 画面的演示备份；若本包有 `演示录屏/` 则优先用仓内文件。

## 演示口径（务必对齐）

- **库**：`univ_course_rag_cn_v2`，规模 **4 门课 / 27 份 PDF / 2,501 chunks**
- **课程**：线性代数、概率论与统计学、人力资源管理、教育学原理
- **检索**：演示默认 **dense**；Hybrid / BM25 / rerank 已实现可开关，**不作中期主结论**；rerank 演示关闭
- **生成**：DeepSeek（`deepseek-flash`）；Embedding：BGE-M3
- **弱规则验收**（非人工正确率）：可答题预期文档/页 **12/12**，拒答 **4/4**
- **22 题真实模型开发者核验**（分层，勿合成准确率；详见 [`研究证据/results/retrieval-compare-2026-10-20.md`](研究证据/results/retrieval-compare-2026-10-20.md)）：端到端可答题成功率 Dense **15/17** / Hybrid **16/17**；已回答题事实要点通过率 **15/16 / 16/16**；已回答题引用支持通过率均 **16/16**；严格预期页命中均 **12/16**（**不叫引用错误率**）；明显课外问题正确拒答均 **5/5**。verifier=developer，不可外推；不得宣称 Hybrid 显著更优。
- **禁止宣称**：人工事实正确率、生产可用、通用 OCR/公式/图表理解、供应商账单已核对、阈值已校准、困难拒答/跨页能力已专项验证

## 固定演示问句

在**线性代数**课内：

1. **LA-01（有引用）**：`根据线性代数讲义，线性代数主要研究哪两类对象？`  
   预期：有回答与引用；点引用打开原 PDF（URL 含 `#page=`）。
2. **LA-R（拒答）**：`根据线性代数讲义，如何用 SQL 创建数据库表并插入数据？`  
   预期：依据不足 / `NO_EVIDENCE`，不编造 SQL。
3. **PERM（无权限）**：打开未加入课程的问答页 → 无权限提示（403）；若账号已加入全部四课，口头说明 API 验收或临时撤权后恢复。

完整顺序见 [`docs/中期演示运行卡.md`](../docs/中期演示运行卡.md)。

## 角色账号（本地 seed）

演示用三角色一般为 `admin` / `teacher` / `student`。本地 seed 默认口令以 `backend/app/config.py` 配置为准；不要将口令写入 PPT、录屏或公开群。若本机已修改口令，以负责人私聊为准。

## 怎么用 PPT / 提纲

1. **优先**：打开 [`答辩提纲.md`](答辩提纲.md)，按大纲自做或改写终稿；对齐 **v6-candidate** 四亮点与分层指标。
2. **候选稿**：用 Office / WPS 打开 `汇报PPT/中期汇报-v6-candidate.pptx`，对照 `讲稿-v6-candidate.md`（知识点详解）。
3. 现场若演示失败：改用 `彩排截图/`（含 10 PERM、11 系统故障），并按运行卡「故障降级」说明边界。

## 怎么彩排（有本机环境时）

按 [`docs/中期演示运行卡.md`](../docs/中期演示运行卡.md)：确认默认库 `cn_v2` 与 `UPLOAD_DIR=.../uploads_v2`，`RERANKER_BACKEND=disabled`，模型 `deepseek-flash`，启动后端 `:8000` 与前端 `:5173`，走学生 → 教师 → Admin。  
**不要**在答辩现场提交 `.env`、重新入库或启用 rerank。本机模型 id 若刚对齐过 flash，**建议用 LA-01/LA-R 再彩排一次**。
