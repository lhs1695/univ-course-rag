# 课程知识库 · 学生端 MASTER

产品：university course knowledge QA student app / 高校课程知识库学生端。

ui-ux-pro-max 两次检索分别偏向社区落地页与儿童教育，未找到完整适配的产品模式；不照搬其模式。采用已匹配的 Minimalism & Swiss Style 与 skill 的通用交互规范，建立以下唯一系统。

- 气质：安静、可信、具有大学阅读室的秩序。书页与页码是产品识别元素，拒绝营销式统计与装饰图表。
- 结构：桌面 232px 白色侧导航 + 浅蓝灰工作区；课程书架为两列目录，问答为居中阅读流，依据置于回答下方。手机改为顶部紧凑导航与单列。
- 色彩：主色 #2563EB，主色文字白；正文 #0F172A；次要文字 #475569；背景 #F8FAFC；纸面白；分隔 #CBD5E1；页码标记 #FEF3C7 / #92400E；错误 #B91C1C。颜色仅用于主要动作、选中位置、页码和状态。
- 字体：中文系统无衬线（Microsoft YaHei / PingFang SC），阅读标题用系统宋体（SimSun / Songti SC）；不依赖远程字体。正文 16px / 1.7；标题 28–36px；辅助文字 13px；页码使用等宽数字。
- 间距：4/8/16/24/32/48；阅读宽度 800px，最大工作区 1120px；面板圆角 12px，输入 8px；1px 边框，无浮夸阴影。
- 交互：每页一个主任务；文本与图标同现；表单可见 label，允许自动填充与粘贴；44px 控件；清晰焦点环。悬停 180ms；尊重 reduced-motion。
- 数据：课程、资料、回答均来自现有 API；历史和草稿沿用按用户/课程隔离的内存适配器。依据保留摘录、文件名、页码，链接 content_url#page=N，新标签打开。
- 状态：加载、空课程/资料、检索中、缺少依据、失败重试、登录失效均明确表达；不自动触发任何云问答。
- 复用：Vue 3 / Vue Router / Element Plus（现有版本）；复用 api、session、courseAccess、askHistory、drafts、AnswerBody 与资料显示适配器。只新增学生布局与展示，无新依赖、后端改动。
